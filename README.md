論理回路シミュレーターを作成して下さい

ブラウザ上で動く、シンプルで視覚的な論理回路シミュレーターのコードを作成しました。
HTMLファイル1つで構成されているため、コードをコピーして .html 拡張子（例: index.html）で保存し、ブラウザで開くだけですぐに動かせます。

🚀 実装する機能
入力（INPUT）: クリックすると 0 と 1 が切り替わります。

基本ゲート: AND, OR, NOT, XOR の4種類。

出力（OUTPUT）: 最終的な計算結果を表示します。

        // 入力状態の管理 (0: OFF, 1: ON)
        const states = {
            'and-in1': 0, 'and-in2': 0,
            'or-in1': 0, 'or-in2': 0,
            'not-in': 0,
            'xor-in1': 0, 'xor-in2': 0
        };

        // ボタンがクリックされたときの処理
        function toggleInput(id) {
            const btn = document.getElementById(id);
            states[id] = states[id] === 0 ? 1 : 0;
            
            // 見た目の更新
            btn.textContent = states[id];
            if (states[id] === 1) {
                btn.classList.add('on');
            } else {
                btn.classList.remove('on');
            }

            // 回路全体の再計算
            updateCircuit();
        }

        // 各論理ゲートの計算と出力の更新
        function updateCircuit() {
            // AND: 両方 1 のとき 1
            const andResult = states['and-in1'] & states['and-in2'];
            updateOutput('and-out', andResult);

            // OR: どちらか片方でも 1 のとき 1
            const orResult = states['or-in1'] | states['or-in2'];
            updateOutput('or-out', orResult);

            // NOT: 反転 (1なら0、0なら1)
            const notResult = states['not-in'] === 0 ? 1 : 0;
            updateOutput('not-out', notResult);

            // XOR: 入力が異なるとき 1
            const xorResult = states['xor-in1'] ^ states['xor-in2'];
            updateOutput('xor-out', xorResult);
        }

        // 出力UIの更新用ヘルパー関数
        function updateOutput(id, value) {
            const outEl = document.getElementById(id);
            outEl.textContent = value;
            if (value === 1) {
                outEl.classList.add('on');
            } else {
                outEl.classList.remove('on');
            }
        }

        // 初期化
        updateCircuit();
    </script>

青い数字のボタンを押すと値が変わり、右側の出力（緑/グレー）がリアルタイムに連動します。

ドラッグ＆ドロップでゲート同士を線で繋ぎたい

ドラッグ＆ドロップでゲートを配置し、端子同士を線で繋ぐことができる、より本格的なインタラクティブ論理回路シミュレーターを作成しました。

HTML5の Canvas を使用して線（配線）を描画し、直感的に操作できるようにしています。こちらも先ほどと同様、HTMLファイル1つで完結しているため、コピペしてブラウザで開くだけで動きます。

📄 ソースコード (advanced_simulator.html)

<body>

    <h1>インタラクティブ論理回路シミュレーター</h1>
    
    <div class="toolbar">
        <strong>ゲート追加:</strong>
        <button class="btn" onclick="addGate('INPUT')">INPUT</button>
        <button class="btn" onclick="addGate('AND')">AND</button>
        <button class="btn" onclick="addGate('OR')">OR</button>
        <button class="btn" onclick="addGate('NOT')">NOT</button>
        <button class="btn" onclick="addGate('OUTPUT')">OUTPUT</button>
        <button class="btn btn-clear" onclick="clearCircuit()">全消去</button>

    <div id="canvas-container">
        <canvas id="circuitCanvas" width="800" height="500"></canvas>
    </div>

    <div class="instructions">
        <strong>【操作方法】</strong><br>
        ・<strong>移動:</strong> ゲートの真ん中をドラッグして動かせます。<br>
        ・<strong>配線:</strong> 出力端子（右側の○）から入力端子（左側の○）へドラッグすると線を繋げます。<br>
        ・<strong>操作:</strong> INPUTゲートをダブルクリックすると `0` と `1` が切り替わります。

    <script>
        const canvas = document.getElementById('circuitCanvas');
        const ctx = canvas.getContext('2d');

        let gates = [];
        let connections = []; // { fromGateId, toGateId, toInputIndex }

        let draggedGate = null;
        let dragOffsetX = 0;
        let dragOffsetY = 0;

        let drawingWire = null; // { fromGate, startX, startY, currentX, currentY }

        // ゲートの定義クラス
        class Gate {
            constructor(type, x, y) {
                this.id = Date.now() + Math.random().toString(36).substr(2, 5);
                this.type = type;
                this.x = x;
                this.y = y;
                this.width = 80;
                this.height = 50;
                this.inputs = (type === 'AND' || type === 'OR') ? [0, 0] : (type === 'NOT' || type === 'OUTPUT') ? [0] : []; 
                this.output = 0;
            }

            // 端子の座標を取得
            getPinPositions() {
                const pins = { inputs: [], output: null };
                
                // 入力端子 (左側)
                if (this.inputs.length === 1) {
                    pins.inputs.push({ x: this.x, y: this.y + this.height / 2 });
                } else if (this.inputs.length === 2) {
                    pins.inputs.push({ x: this.x, y: this.y + this.height / 3 });
                    pins.inputs.push({ x: this.x, y: this.y + (this.height / 3) * 2 });
                }

                // 出力端子 (右側)
                if (this.type !== 'OUTPUT') {
                    pins.output = { x: this.x + this.width, y: this.y + this.height / 2 };
                }
                return pins;
            }

            draw() {
                // ゲート本体の描画
                ctx.fillStyle = this.type === 'INPUT' ? '#3498db' : this.type === 'OUTPUT' ? '#95a5a6' : '#2c3e50';
                if (this.type === 'INPUT' && this.output === 1) ctx.fillStyle = '#2ecc71';
                if (this.type === 'OUTPUT' && this.inputs[0] === 1) ctx.fillStyle = '#2ecc71';

                ctx.beginPath();
                ctx.roundRect(this.x, this.y, this.width, this.height, 6);
                ctx.fill();

                // テキスト描画
                ctx.fillStyle = '#ffffff';
                ctx.font = 'bold 14px Arial';
                ctx.textAlign = 'center';
                ctx.textBaseline = 'middle';
                let label = this.type;
                if (this.type === 'INPUT') label = `IN: ${this.output}`;
                if (this.type === 'OUTPUT') label = `OUT: ${this.inputs[0] || 0}`;
                ctx.fillText(label, this.x + this.width / 2, this.y + this.height / 2);

                // 端子(○)の描画
                const pins = this.getPinPositions();
                ctx.fillStyle = '#e74c3c';
                
                pins.inputs.forEach(pin => {
                    ctx.beginPath();
                    ctx.arc(pin.x, pin.y, 5, 0, Math.PI * 2);
                    ctx.fill();
                });

                if (pins.output) {
                    ctx.beginPath();
                    ctx.arc(pins.output.x, pins.output.y, 5, 0, Math.PI * 2);
                    ctx.fill();
                }
            }
        }

        // ゲートの追加
        function addGate(type) {
            const x = 50 + Math.random() * 100;
            const y = 80 + Math.random() * 200;
            gates.push(new Gate(type, x, y));
            render();
        }

        // 全消去
        function clearCircuit() {
            gates = [];
            connections = [];
            render();
        }

        // 論理回路の計算ロジック
        function evaluateCircuit() {
            // トポロジカルソートの代わりに、簡易的に複数回ループして状態を伝播させる
            for (let i = 0; i < 5; i++) { 
                // 1. 配線を通じて出力を入力へコピー
                connections.forEach(conn => {
                    const fromGate = gates.find(g => g.id === conn.fromGateId);
                    const toGate = gates.find(g => g.id === conn.toGateId);
                    if (fromGate && toGate) {
                        toGate.inputs[conn.toInputIndex] = fromGate.output;
                    }
                });

                // 2. 各ゲートの論理計算
                gates.forEach(gate => {
                    if (gate.type === 'AND') {
                        gate.output = (gate.inputs[0] && gate.inputs[1]) ? 1 : 0;
                    } else if (gate.type === 'OR') {
                        gate.output = (gate.inputs[0] || gate.inputs[1]) ? 1 : 0;
                    } else if (gate.type === 'NOT') {
                        gate.output = gate.inputs[0] === 0 ? 1 : 0;
                    } else if (gate.type === 'OUTPUT') {
                        gate.output = gate.inputs[0] || 0;
                    }
                });
            }
        }

        // 描画メイン処理
        function render() {
            ctx.clearRect(0, 0, canvas.width, canvas.height);

            // 背景のグリッド線
            ctx.strokeStyle = '#f0f0f0';
            ctx.lineWidth = 1;
            for(let x=0; x<canvas.width; x+=20) {
                ctx.beginPath(); ctx.moveTo(x, 0); ctx.lineTo(x, canvas.height); ctx.stroke();
            }
            for(let y=0; y<canvas.height; y+=20) {
                ctx.beginPath(); ctx.moveTo(0, y); ctx.lineTo(canvas.width, y); ctx.stroke();
            }

            evaluateCircuit();

            // 配線の描画
            ctx.strokeStyle = '#2980b9';
            ctx.lineWidth = 3;
            connections.forEach(conn => {
                const fromGate = gates.find(g => g.id === conn.fromGateId);
                const toGate = gates.find(g => g.id === conn.toGateId);
                if (fromGate && toGate) {
                    const start = fromGate.getPinPositions().output;
                    const end = toGate.getPinPositions().inputs[conn.toInputIndex];
                    
                    ctx.beginPath();
                    ctx.moveTo(start.x, start.y);
                    // 美しい曲線の配線
                    ctx.bezierCurveTo(start.x + 40, start.y, end.x - 40, end.y, end.x, end.y);
                    ctx.stroke();
                }
            });

            // ドラッグ中の配線を描画
            if (drawingWire) {
                ctx.strokeStyle = '#e67e22';
                ctx.lineWidth = 2;
                ctx.setLineDash([4, 4]);
                ctx.beginPath();
                ctx.moveTo(drawingWire.startX, drawingWire.startY);
                ctx.lineTo(drawingWire.currentX, drawingWire.currentY);
                ctx.stroke();
                ctx.setLineDash([]); // ダッシュを戻す
            }

            // ゲートの描画
            gates.forEach(gate => gate.draw());
        }

        // --- マウスイベントハンドリング ---

        canvas.addEventListener('mousedown', (e) => {
            const rect = canvas.getBoundingClientRect();
            const mouseX = e.clientX - rect.left;
            const mouseY = e.clientY - rect.top;

            // 1. 出力ピンがクリックされたか判定（配線開始）
            for (let gate of gates) {
                const pins = gate.getPinPositions();
                if (pins.output) {
                    const dist = Math.hypot(pins.output.x - mouseX, pins.output.y - mouseY);
                    if (dist < 8) {
                        drawingWire = {
                            fromGate: gate,
                            startX: pins.output.x,
                            startY: pins.output.y,
                            currentX: mouseX,
                            currentY: mouseY
                        };
                        return;
                    }
                }
            }

            // 2. ゲート本体がクリックされたか判定（ドラッグ開始）
            for (let i = gates.length - 1; i >= 0; i--) {
                const gate = gates[i];
                if (mouseX >= gate.x && mouseX <= gate.x + gate.width &&
                    mouseY >= gate.y && mouseY <= gate.y + gate.height) {
                    draggedGate = gate;
                    dragOffsetX = mouseX - gate.x;
                    dragOffsetY = mouseY - gate.y;
                    
                    // 配列の最後尾に入れ替えて最前面に描画させる
                    gates.push(gates.splice(i, 1)[0]);
                    return;
                }
            }
        });

        canvas.addEventListener('mousemove', (e) => {
            const rect = canvas.getBoundingClientRect();
            const mouseX = e.clientX - rect.left;
            const mouseY = e.clientY - rect.top;

            if (draggedGate) {
                draggedGate.x = mouseX - dragOffsetX;
                draggedGate.y = mouseY - dragOffsetY;
                render();
            } else if (drawingWire) {
                drawingWire.currentX = mouseX;
                drawingWire.currentY = mouseY;
                render();
            }
        });

        canvas.addEventListener('mouseup', (e) => {
            const rect = canvas.getBoundingClientRect();
            const mouseX = e.clientX - rect.left;
            const mouseY = e.clientY - rect.top;

            if (drawingWire) {
                // 入力ピンの上にドロップされたか判定（配線完了）
                for (let gate of gates) {
                    if (gate.id === drawingWire.fromGate.id) continue; // 自分自身には繋げない
                    
                    const pins = gate.getPinPositions();
                    for (let i = 0; i < pins.inputs.length; i++) {
                        const pin = pins.inputs[i];
                        const dist = Math.hypot(pin.x - mouseX, pin.y - mouseY);
                        if (dist < 10) {
                            // 既存の同じ入力への接続を削除（上書き）
                            connections = connections.filter(c => !(c.toGateId === gate.id && c.toInputIndex === i));
                            
                            // 新しい接続を追加
                            connections.push({
                                fromGateId: drawingWire.fromGate.id,
                                toGateId: gate.id,
                                toInputIndex: i
                            });
                            break;
                        }
                    }
                }
                drawingWire = null;
                render();
            }

            draggedGate = null;
        });

        // ダブルクリックでINPUTの値を切り替え
        canvas.addEventListener('dblclick', (e) => {
            const rect = canvas.getBoundingClientRect();
            const mouseX = e.clientX - rect.left;
            const mouseY = e.clientY - rect.top;

            gates.forEach(gate => {
                if (gate.type === 'INPUT' &&
                    mouseX >= gate.x && mouseX <= gate.x + gate.width &&
                    mouseY >= gate.y && mouseY <= gate.y + gate.height) {
                    gate.output = gate.output === 0 ? 1 : 0;
                    render();
                }
            });
        });

        // 初期状態でいくつかゲートを配置しておく
        addGate('INPUT');
        addGate('INPUT');
        addGate('AND');
        addGate('OUTPUT');

直感的なキャンバス操作:

上部のツールバーから好きなゲートをいくつでも追加できます。

ゲートのボディをドラッグして、画面内の好きな場所に配置（レイアウト）できます。

ドラッグ配線機能:

ゲート右側の赤い丸（出力）からドラッグするとオレンジの点線が伸び、別のゲートの左側にある赤い丸（入力）に重ねて離すと、きれいな曲線で接続されます。

インタラクティブな連動:

INPUT ゲートをダブルクリックすると、0 と 1 が切り替わり、流れる信号（ON/OFF）がリアルタイムに計算されて全体のゲートや OUTPUT の色（緑＝ON、グレー＝OFF）に反映されます。

        const canvas = document.getElementById('circuitCanvas');
        const ctx = canvas.getContext('2d');

        let gates = [];
        let connections = [];

        let draggedGate = null;
        let dragOffsetX = 0;
        let dragOffsetY = 0;

        // ゲートクラス
        class Gate {
            constructor(type, x, y) {
                this.id = Date.now() + Math.random().toString(36).substr(2, 5);
                this.type = type;
                this.x = x;
                this.y = y;
                this.width = 80;
                this.height = 50;
                this.inputs = (type === 'AND' || type === 'OR') ? [0, 0] : (type === 'NOT' || type === 'OUTPUT') ? [0] : []; 
                this.output = 0;
            }

            // 端子の座標を取得
            getPinPositions() {
                const pins = { inputs: [], output: null };
                
                // 入力端子 (左端)
                if (this.inputs.length === 1) {
                    pins.inputs.push({ x: this.x, y: this.y + this.height / 2 });
                } else if (this.inputs.length === 2) {
                    // ORゲートの場合は少し内側に入力ピンを配置（形状に合わせるため）
                    const offset = this.type === 'OR' ? 8 : 0;
                    pins.inputs.push({ x: this.x + offset, y: this.y + this.height / 4 });
                    pins.inputs.push({ x: this.x + offset, y: this.y + (this.height / 4) * 3 });
                }

                // 出力端子 (右端)
                if (this.type !== 'OUTPUT') {
                    pins.output = { x: this.x + this.width, y: this.y + this.height / 2 };
                }
                return pins;
            }

            draw() {
                // 信号の状態によって色を変更 (ON: 緑, OFF: 暗い青灰色)
                let isActive = false;
                if (this.type === 'INPUT' && this.output === 1) isActive = true;
                if (this.type === 'OUTPUT' && this.inputs[0] === 1) isActive = true;
                if ((this.type === 'AND' || this.type === 'OR' || this.type === 'NOT') && this.output === 1) isActive = true;

                ctx.strokeStyle = '#2c3e50';
                ctx.fillStyle = isActive ? '#2ecc71' : '#ecf0f1';
                ctx.lineWidth = 3;

                const x = this.x;
                const y = this.y;
                const w = this.width;
                const h = this.height;

                ctx.beginPath();
                
                if (this.type === 'INPUT') {
                    // 入力：シンプルな六角形（または長方形）
                    ctx.roundRect(x, y + 10, w - 20, h - 20, 4);
                    ctx.fill(); ctx.stroke();
                    
                    // テキスト
                    ctx.fillStyle = isActive ? '#fff' : '#2c3e50';
                    ctx.font = 'bold 14px Arial';
                    ctx.fillText(`IN: ${this.output}`, x + (w-20)/2, y + h/2);
                    
                } else if (this.type === 'OUTPUT') {
                    // 出力：円形型
                    ctx.arc(x + 20, y + h/2, 20, 0, Math.PI * 2);
                    ctx.fill(); ctx.stroke();
                    
                    ctx.fillStyle = isActive ? '#fff' : '#2c3e50';
                    ctx.font = 'bold 14px Arial';
                    ctx.fillText(`${this.inputs[0] || 0}`, x + 20, y + h/2);

                } else if (this.type === 'AND') {
                    // MIL記号 AND: 左が直線、右が半円
                    ctx.moveTo(x, y);
                    ctx.lineTo(x + w/2, y);
                    ctx.arc(x + w/2, y + h/2, h/2, -Math.PI/2, Math.PI/2, false);
                    ctx.lineTo(x, y + h);
                    ctx.closePath();
                    ctx.fill(); ctx.stroke();
                    
                    // 中央に識別用の薄い文字
                    ctx.fillStyle = 'rgba(44, 62, 80, 0.2)';
                    ctx.font = 'bold 12px Arial';
                    ctx.fillText('AND', x + w/3, y + h/2);

                } else if (this.type === 'OR') {
                    // MIL記号 OR: 左が凹んだ曲線、右が尖った三日月型
                    ctx.moveTo(x, y);
                    // 上の曲線
                    ctx.quadraticCurveTo(x + w*0.4, y, x + w, y + h/2);
                    // 下の曲線
                    ctx.quadraticCurveTo(x + w*0.4, y + h, x, y + h);
                    // 左の凹み線
                    ctx.quadraticCurveTo(x + w*0.25, y + h/2, x, y);
                    ctx.closePath();
                    ctx.fill(); ctx.stroke();

                    ctx.fillStyle = 'rgba(44, 62, 80, 0.2)';
                    ctx.font = 'bold 12px Arial';
                    ctx.fillText('OR', x + w/2, y + h/2);

                } else if (this.type === 'NOT') {
                    // MIL記号 NOT: 三角形 ＋ 先端の小さな丸
                    ctx.moveTo(x, y + 5);
                    ctx.lineTo(x + w - 15, y + h/2);
                    ctx.lineTo(x, y + h - 5);
                    ctx.closePath();
                    ctx.fill(); ctx.stroke();
                    
                    // 先端の○ (反転の丸)
                    ctx.beginPath();
                    ctx.arc(x + w - 7, y + h/2, 6, 0, Math.PI * 2);
                    ctx.fill(); ctx.stroke();
                }

                // 端子(赤色の接続ポイント○)の描画
                const pins = this.getPinPositions();
                ctx.fillStyle = '#e74c3c';
                ctx.lineWidth = 1;
                
                pins.inputs.forEach(pin => {
                    ctx.beginPath();
                    ctx.arc(pin.x, pin.y, 5, 0, Math.PI * 2);
                    ctx.fill(); ctx.stroke();
                });

                if (pins.output) {
                    ctx.beginPath();
                    ctx.arc(pins.output.x, pins.output.y, 5, 0, Math.PI * 2);
                    ctx.fill(); ctx.stroke();
                }
            }

            const x = 80 + Math.random() * 100;
            const y = 80 + Math.random() * 200;

            render();
        }

        // 全消去
        function clearCircuit() {
            gates = [];
            connections = [];
            render();
        }

        // 論理回路の計算
        function evaluateCircuit() {
            for (let i = 0; i < 5; i++) { 
                connections.forEach(conn => {
                    const fromGate = gates.find(g => g.id === conn.fromGateId);
                    const toGate = gates.find(g => g.id === conn.toGateId);
                    if (fromGate && toGate) {
                        toGate.inputs[conn.toInputIndex] = fromGate.output;
                    }
                });

                gates.forEach(gate => {
                    if (gate.type === 'AND') {
                        gate.output = (gate.inputs[0] && gate.inputs[1]) ? 1 : 0;
                    } else if (gate.type === 'OR') {
                        gate.output = (gate.inputs[0] || gate.inputs[1]) ? 1 : 0;
                    } else if (gate.type === 'NOT') {
                        gate.output = gate.inputs[0] === 0 ? 1 : 0;
                    } else if (gate.type === 'OUTPUT') {
                        gate.output = gate.inputs[0] || 0;
                    }
                });
            }
        }

        // 描画メイン処理
        function render() {
            ctx.clearRect(0, 0, canvas.width, canvas.height);
            ctx.textAlign = 'center';
            ctx.textBaseline = 'middle';

            // 背景のグリッド線
            ctx.strokeStyle = '#f5f5f5';
            ctx.lineWidth = 1;
            for(let x=0; x<canvas.width; x+=20) {
                ctx.beginPath(); ctx.moveTo(x, 0); ctx.lineTo(x, canvas.height); ctx.stroke();
            }
            for(let y=0; y<canvas.height; y+=20) {
                ctx.beginPath(); ctx.moveTo(0, y); ctx.lineTo(canvas.width, y); ctx.stroke();
            }

            evaluateCircuit();

            // 配線の描画
            connections.forEach(conn => {
                const fromGate = gates.find(g => g.id === conn.fromGateId);
                const toGate = gates.find(g => g.id === conn.toGateId);
                if (fromGate && toGate) {
                    const start = fromGate.getPinPositions().output;
                    const end = toGate.getPinPositions().inputs[conn.toInputIndex];
                    
                    // 信号が流れている線は青、流れていない線はグレー
                    ctx.strokeStyle = fromGate.output === 1 ? '#3498db' : '#bdc3c7';
                    ctx.lineWidth = 3;
                    
                    ctx.beginPath();
                    ctx.moveTo(start.x, start.y);
                    ctx.bezierCurveTo(start.x + 40, start.y, end.x - 40, end.y, end.x, end.y);
                    ctx.stroke();
                }
            });

            // ドラッグ中の配線を描画
            if (drawingWire) {
                ctx.strokeStyle = '#e67e22';
                ctx.lineWidth = 2;
                ctx.setLineDash([4, 4]);
                ctx.beginPath();
                ctx.moveTo(drawingWire.startX, drawingWire.startY);
                ctx.lineTo(drawingWire.currentX, drawingWire.currentY);
                ctx.stroke();
                ctx.setLineDash([]);
            }

            // ゲートの描画
            gates.forEach(gate => gate.draw());
        }

# MIL記号 論理回路シミュレーター

ウェブブラウザ上で直感的に論理回路を構築・検証できるインタラクティブなシミュレーターです。
JIS / MIL 規格準拠の論理ゲート記号を採用しており、ドラッグ＆ドロップによる自由な配置や端子間の結線、リアルタイムな論理演算シミュレーションが可能です。

---

## 🌟 主な特徴

- **標準MIL記号の採用**: AND、OR、NOTなどの論理ゲートを標準的なMIL記号デザインで再現。
- **ドラッグ＆ドロップ操作**: ゲートの自由な配置変更や、出力端子から入力端子への直感的な配線構築が可能。
- **リアルタイムシミュレーション**: 入力値（0 / 1）の切り替えに応じて、回路全体の論理演算結果および信号の伝播状況（ハイライト表示）を瞬時に更新。
- **完全スタンドアロン型**: HTML/CSS/JavaScript が1つのファイルに完結しているため、Webサーバー不要でローカルのブラウザのみで即座に動作。

---

## 🚀 使い方

1. 本リポジトリの `mil_symbol_simulator.html`（または `index.html`）をダウンロードします。
2. ダウンロードした HTML ファイルをダブルクリックし、お使いの Web ブラウザ（Chrome, Edge, Safari, Firefox 等）で開きます。

### 基本操作方法

| 操作 | 手順 |
| :--- | :--- |
| **ゲートの追加** | 画面上部のツールバーから追加したいコンポーネント（`INPUT`, `AND`, `OR`, `NOT`, `OUTPUT`）をクリック |
| **ゲートの移動** | コンポーネント本体をドラッグ＆ドロップ |
| **配線（結線）** | ゲート右側の**赤丸（出力端子）**から、他のゲート左側の**赤丸（入力端子）**へドラッグ＆ドロップ |
| **入力値の変更** | `INPUT` ゲートを**ダブルクリック**すると `0` と `1` が切り替わります |
| **全消去** | ツールバーの「全消去」ボタンをクリックでキャンバスをリセット |

---

## 🧩 対応コンポーネント仕様

| コンポーネント | 入力数 | 出力数 | 記号形状 / 概要 |
| :--- | :---: | :---: | :--- |
| **INPUT** | 0 | 1 | 入力ソース。ダブルクリックで `0` (OFF) と `1` (ON) を切り替え |
| **AND** | 2 | 1 | ANDゲート（論理積）。両方の入力が `1` のとき `1` を出力 |
| **OR** | 2 | 1 | ORゲート（論理和）。いずれかの入力が `1` のとき `1` を出力 |
| **NOT** | 1 | 1 | NOTゲート（論理否定）。入力の論理値を反転して出力 |
| **OUTPUT** | 1 | 0 | 出力モニター。接続された入力の最新論理値をリアルタイム表示 |
