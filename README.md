# MIL記号 論理回路シミュレーター

ウェブブラウザ上で直感的に論理回路を構築・検証できるインタラクティブなシミュレーターです。
JIS / MIL 規格準拠の論理ゲート記号を採用しており、ドラッグ＆ドロップによる自由な配置や端子間の結線、リアルタイムな論理演算シミュレーションが可能です。

---

## 🌟 主な特徴

- **標準MIL記号の採用**: AND、OR、NOTなどの論理ゲートを標準的なMIL記号デザインで再現。
- **ドラッグ＆ドロップ操作**: ゲートの自由な配置変更や、出力端子から入力端子への直感的な配線構築が可能。
- **リアルタイムシミュレーション**: 入力値（0 / 1）の切り替えに応じて、回路全体の論理演算結果および信号の伝播状況（ハイライト表示）を瞬時に更新。
- **完全スタンドアロン型**: HTML/CSS/JavaScript が1つのファイルに完結しているため、Webサーバー不要でローカルのブラウザのみで即座に動作。

---

## 🚀 使い方

1. 本リポジトリの `mil_symbol_simulator.html`（または `index.html`）をダウンロードします。
2. ダウンロードした HTML ファイルをダブルクリックし、お使いの Web ブラウザ（Chrome, Edge, Safari, Firefox 等）で開きます。

### 基本操作方法

| 操作 | 手順 |
| :--- | :--- |
| **ゲートの追加** | 画面上部のツールバーから追加したいコンポーネント（`INPUT`, `AND`, `OR`, `NOT`, `OUTPUT`）をクリック |
| **ゲートの移動** | コンポーネント本体をドラッグ＆ドロップ |
| **配線（結線）** | ゲート右側の**赤丸（出力端子）**から、他のゲート左側の**赤丸（入力端子）**へドラッグ＆ドロップ |
| **入力値の変更** | `INPUT` ゲートを**ダブルクリック**すると `0` と `1` が切り替わります |
| **全消去** | ツールバーの「全消去」ボタンをクリックでキャンバスをリセット |

---

## 🧩 対応コンポーネント仕様

| コンポーネント | 入力数 | 出力数 | 記号形状 / 概要 |
| :--- | :---: | :---: | :--- |
| **INPUT** | 0 | 1 | 入力ソース。ダブルクリックで `0` (OFF) と `1` (ON) を切り替え |
| **AND** | 2 | 1 | ANDゲート（論理積）。両方の入力が `1` のとき `1` を出力 |
| **OR** | 2 | 1 | ORゲート（論理和）。いずれかの入力が `1` のとき `1` を出力 |
| **NOT** | 1 | 1 | NOTゲート（論理否定）。入力の論理値を反転して出力 |
| **OUTPUT** | 1 | 0 | 出力モニター。接続された入力の最新論理値をリアルタイム表示 |
